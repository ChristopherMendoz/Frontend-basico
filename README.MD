Este proyecto corresponde al taller práctico de **Diseño de sistemas en Internet**.
Su objetivo es demostrar la estructura básica de una página web utilizando HTML.

## Contenido de la página

La página incluye:

- Un encabezado principal con el nombre del estudiante(Osea yo).
- Un párrafo de presentación personal.
- Una imagen.
- Una lista de intereses y habilidades.
- Enlaces.
- La estructura principal de un documento HTML mediante las etiquetas
  `html`, `head` y `body`.
- El uso de encabezados, párrafos, listas y enlaces.
